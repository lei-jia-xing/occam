* 核心原则 (Core Invariants)
- [Haskell 保持方言无关] 依赖图构建与规约算法不解析 SQL 语法，所有 AST 与词法提取严格归属 Rust 前端。
- [上游优先，不做 Fallback] 语法解析严格依托 =sqlparser-rs=，不手写脆弱的正则或 token 解析器。
- [速度优先，语句内重写可选] 默认聚焦高吞吐的语句级规约（切片、闭包、ddmin）；语句内微语法修剪通过 =--intra-statement= 按需开启。
