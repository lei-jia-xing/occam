* Core Invariants
- [Dialect-Agnostic Engine] Haskell reducer and dependency DAG builder remain dialect-agnostic; all AST parsing and lexical extraction belong exclusively to the Rust frontend (`sqlparser-rs`).
- [No Fragile Fallbacks] Defer unparsed SQL constructs to upstream `sqlparser-rs` as barriers rather than writing fragile ad-hoc regex or token heuristics.
- [Speed-First Default] Focus on high-throughput statement-level reductions (backward slicing, closure search, ddmin, audit); intra-statement AST rewrites remain opt-in. When enabled, generated edits use ordinal-forward category sweeps until a complete unchanged cycle or explicit Evaluation-budget interruption (details below).
- [Unix-Native Ergonomics] Pure reduced SQL on `stdout` when piped, diagnostics and dynamic progress on `stderr`, and native shell auto-completions via `usage`.

** DONE Ordinal-forward sweep traversal of generated syntax edits [2026-11]
- Removed hidden consecutive-rejection and total-attempt cutoffs. Generated eligible edits remain oracle-gated until the existing Evaluation budget interrupts or a complete unchanged cycle establishes exhaustion.
- Stable category order is Clause, List, Constraint, Type, Expression, then Literal; each fresh category snapshot retains parser-emitted order. Rejection/nonshrinking advances the ordinal; acceptance triggers a fresh parse and resumes at the accepted ordinal. All categories finish before a new full cycle; candidates before the cursor, including newly inserted or shifted edits, are revisited from ordinal zero on that cycle, and the pass repeats iff the prior cycle shrank SQL. This forward priority may change finite-budget checkpoints relative to restart-from-zero scheduling.
- Every accepted candidate strictly shrinks bytes and triggers one parse before traversal resumes; exact spans are never reused across changed SQL. Equal-length canonicalization such as `1` to `0` remains unsupported. Only an unchanged full cycle establishes generated-edit exhaustion; this is not full AST coverage or a global-minimality guarantee.
