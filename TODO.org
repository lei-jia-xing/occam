* Core Invariants
- [Dialect-Agnostic Engine] Haskell reducer and dependency DAG builder remain dialect-agnostic; all AST parsing and lexical extraction belong exclusively to the Rust frontend (`sqlparser-rs`).
- [No Fragile Fallbacks] Defer unparsed SQL constructs to upstream `sqlparser-rs` as barriers rather than writing fragile ad-hoc regex or token heuristics.
- [Speed-First Default] Focus on high-throughput statement-level reductions (backward slicing, closure search, ddmin, audit); intra-statement AST rewrites are opt-in via `--intra-statement`.
- [Unix-Native Ergonomics] Pure reduced SQL on `stdout` when piped, diagnostics and dynamic progress on `stderr`, and native shell auto-completions via `usage`.
