* Core Invariants
- [Pure-Haskell Strict Frontend] All SQL lexing, parsing, semantic fact extraction, and byte-span edit generation live natively in Haskell with zero FFI/Cargo/C-toolchain dependencies.
- [Strict Dialect Isolation & Extensibility] No `generic` fallback dialect and no cross-dialect grammar bleed. Shared SQL core constructs combine with explicit per-dialect specifications (`DialectSpec`) so each supported DBMS enforces its real grammar (e.g., rejecting invalid syntax such as `CREATE TEMP POLICY`) and adding new dialects remains modular.
- [Decoupled Boundary & Exact Spans] Statement splitting and UTF-8 `ByteSpan` tracking are decoupled from statement-level grammar parsing; AST rewrites emit exact source-byte edits only and never regenerate SQL via AST pretty-printing.
- [Speed-First Default] High-throughput statement-level reductions (backward slicing, closure search, ddmin, audit) remain the default; intra-statement AST rewrites remain opt-in using ordinal-forward category sweeps until a full unchanged cycle or explicit budget interruption.
- [Unix-Native Ergonomics] Pure reduced SQL on `stdout` when piped, diagnostics and dynamic progress on `stderr`, and native shell auto-completions.
