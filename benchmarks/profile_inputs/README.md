# [#B] profiling inputs + protocol: syntax-edit IR gating question

Purpose (investigation only): decide whether unconsumed regular syntax-edit
IR materialized during statement analysis is worth gating (good's proposal).
No fixture-specific production rules: any fix must be generic and measured.

## Inputs

`pairs-004/016/064/256.sql` under `benchmarks/benchmark_artifacts/
profile-inputs-20261116-a/` (gitignored bundle): independent `CREATE TABLE` +
`INSERT` pairs (no FKs, no shared state; 8/32/128/512 statements) from
`benchmarks/tools/gen_profile_inputs.py` (seed pinned in the bundle
`MANIFEST.json`). Generation asserts byte-determinism (two runs identical)
and validity (every file executes clean in SQLite). Only this doc and the
generator live in the tree; generated bytes live in the bundle.

## Predicate (engine mechanics only)

Standalone `exit 0` predicate. This is explicitly a parser/allocator
microbenchmark of engine mechanics, NOT a DB reduction, NOT comparable to any
reduction score, and NOT any kind of tool victory.

## A-run protocol (after A proof, idle resources only)

Run each input under the frozen A `occam` binary, default statement-only
flags (no `--intra-statement`), e.g.:

```
<FROZEN>/occam <INPUT> --oracle "exit 0" --dialect sqlite \
  --timeout 10 --budget 600 --out <OUT> --log-format json +RTS -s -RTS
```

`+RTS -s` (binary is `-rtsopts` enabled) reports allocation and peak residency
on stderr; if RTS stats are ever unsupported, fall back to wall + cost only.
Never run timing on CPU0 while the 48-child triad runs; helpers stay immutable
during triad runs.

Harvest per input (exact argv, input SHA from the bundle `MANIFEST.json`, source SHA from
the frozen `SOURCES.sha256`): cost-section `snapshotParseFfiMicros` vs
`snapshotParseDecodeMicros` (expect `statement-only` only), RTS bytes
allocated + max residency, and wall time. Completion (empty output) is
expected; anything else is reported, not retried into shape.

## B comparison rule

OldA-frozen vs newB-frozen with the SAME helper bytes, mode, resources, and
counts — never against the uninstrumented 632 baseline. The gate decision
follows the measured FFI/decode/alloc split; good owns the fix, this
workstream owns the measurements and evidence.
