# Occam Formal Verification (Lean 4)

Formal machine-checked proofs for the Occam SQL test-case reducer:
- `Proofs.DAG`: Temporal dependency DAG acyclicity, slicing soundness, and closure minimality.
- `Proofs.Reduction`: Reduction measure monotonicity, well-founded termination, and fixed-point convergence.
- `Proofs.Minimality`: Single-statement audit 1-minimality and closure 1-minimality.
